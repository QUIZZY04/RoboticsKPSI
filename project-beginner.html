The Smart Lamp

Step into the world of smart automation! This project teaches you how to use an Arduino to sense the environment and make decisions based on light levels.

1. The Bill of Materials

Arduino Uno R3
LDR (Light Sensor)
10k Ohm Resistor
LED & 220Ω Resistor

2. Wiring It Up

1 LDR Connection: Create a voltage divider with the LDR and 10k resistor. Connect the middle to Analog Pin A0.
2 LED Connection: Connect the long leg of the LED to Digital Pin 13 through a 220 ohm resistor.
3 Power: Connect the rails to 5V and GND on the Arduino.

3. The Program (The Brains)

const int ldrPin = A0;
const int ledPin = 13;
const int threshold = 400; 

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int lightVal = analogRead(ldrPin);
  Serial.println(lightVal); 

  if (lightVal < threshold) {
    digitalWrite(ledPin, HIGH); // Turn on lamp
  } else {
    digitalWrite(ledPin, LOW);  // Turn off lamp
  }
  delay(100);
}
